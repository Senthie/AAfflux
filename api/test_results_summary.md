## 🔧 技术实现亮点

### API 兼容性处理

- **问题**: API schema 验证只接受 `['LLM', 'CONDITION', 'CODE', 'HTTP', 'TRANSFORM']` 节点类型
- **解决**: 将原始的 `CHAT`, `OLLAMA`, `AGENT` 类型映射为 `LLM` 类型
- **结果**: 成功绕过 schema 限制，保持功能完整性

### 认证流程优化

- **注册**: 使用正确的 `name` 字段而非 `full_name`
- **登录**: 使用 JSON 格式而非 form data
- **Token**: 正确解析嵌套的 token 结构 `tokens.access_token`

### 依赖关系管理

- **团队 → 工作空间**: 工作空间创建需要 `team_id`
- **工作空间 → 工作流**: 工作流创建需要 `workspace_id`
- **工作流 → 节点**: 节点创建需要 `workflow_id`
